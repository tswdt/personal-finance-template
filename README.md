# 📊 个人财务管理模板

> 一款全自动的个人/家庭财务记账 Excel 模板

## ✨ 功能特色

| 功能 | 说明 |
|------|------|
| 📝 **收支记账** | 逐笔记录日常收入与支出，带示例数据 |
| 📈 **仪表盘** | 自动生成收支分类饼图和月度趋势柱状图 |
| 📊 **月度汇总** | 每月收支自动汇总，同比分析 |
| 🎯 **预算管理** | 设定月度预算，自动监控超支状态 |
| 📂 **类别管理** | 自定义收支类别，灵活配置 |

## 🚀 快速开始

1. 下载 `个人财务管理模板.xlsx`
2. 用 Excel 或 WPS 打开
3. 在「记账记录」表中录入你的收支
4. 切换到「仪表盘」查看自动生成的图表分析

## 📋 工作表说明

| 工作表 | 用途 |
|--------|------|
| 使用说明 | 模板使用指南 |
| 记账记录 | 逐笔记录收支明细（含示例数据） |
| 仪表盘 | 自动汇总图表（饼图 + 柱状图） |
| 月度汇总 | 12个月收支汇总统计 |
| 预算设置 | 按类别设定预算并监控超支 |
| 类别管理 | 自定义收支类别 |

## 💡 使用技巧

- 日期格式：`YYYY-MM-DD`
- 收入和支出都填**正数**，系统自动区分
- 建议每周录入一次，保持数据及时
- 在「预算设置」中填默认算金额即可自动监控

## 🛠️ 技术细节

- 格式：`.xlsx`（Excel 2007+ / WPS 兼容）
- 大小：18 KB
- 公式：SUMIF、SUMPRODUCT、图表自动更新
- 兼容性：Microsoft Excel / WPS Office / LibreOffice Calc
